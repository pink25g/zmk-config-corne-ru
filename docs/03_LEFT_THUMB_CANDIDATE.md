# Кандидат: обычный пробел слева и предсказуемые слои

Это вариант для сравнения, а не подтверждённая на руках эргономика. Буквенная основа QWERTY/ЙЦУКЕН сохранена. Леворукость учтена расположением пробела и цифрового блока; положение мыши неизвестно и не предполагается. ZMK v0.2, платы, BLE и сон не меняются. Клавиатура автоматически не прошивается.

## Большие пальцы

Позиции указаны в порядке записи Corne: левый блок снаружи к центру, правый от центра наружу.

| Позиция | Раньше | Кандидат |
|---|---|---|
| 36, левая внешняя | Shift одним нажатием / Ctrl удержанием | Без изменения |
| 37, левая средняя | Tab / NAV удержанием | NAV сразу при удержании, без ожидания Tab |
| 38, левая внутренняя | Alt | Обычный Space, без таймеров и макросов |
| 39, правая внутренняя | Space / NUM + двойные и тройные нажатия | Backspace / NUM удержанием |
| 40, правая средняя | Enter / FN | Enter / FN с явной tap-preferred настройкой |
| 41, правая внешняя | Shift одним нажатием / Ctrl удержанием | Без изменения |

Обычные Tab сверху слева и Backspace сверху справа остаются. Для длинного удаления можно удерживать обычный Backspace; для совмещённой кнопки — быстро нажать, затем нажать и удерживать (quick-tap 180 мс). Первое удержание совмещённой кнопки включает NUM через 220 мс.

## Цифры и навигация

NUM удерживается правым большим пальцем. Цифры 7–9 / 4–6 / 1–3 находятся под WER / SDF / XCV, то есть в столбцах 2–4 левой половины; 0 — справа от 3. Десятичная точка — слева от 1 при русской раскладке ОС. Это верхний цифровой ряд HID, не отдельные numpad-коды: разделитель Excel зависит от настроек ОС/Excel и требует проверки.

NAV удерживается левым большим пальцем. Стрелки на правой домашней строке: J ←, K ↓, L ↑, ; →; H — Home, крайняя правая — End. На левой домашней строке NAV — Ctrl, Undo, Cut, Copy, Paste, Redo. На FN снизу слева добавлены отдельные Alt, Tab, Win+Space, Ctrl и Shift. Win+Space — явная комбинация, а не автоматическое определение языка; её действие зависит от настроек Windows.

## Русский текст и символы

- Ё — нижняя внешняя кнопка слева (бывшая прозрачная).
- Э — нижняя внешняя справа (бывшая прозрачная).
- Х и Ъ — первые две кнопки правой верхней строки NAV.
- Точка/запятая на NAV — две последние кнопки левой нижней строки; вопрос, восклицательный знак, кавычки, двоеточие и точка с запятой имеют RU aliases.
- Для русских букв и знаков должна быть включена русская раскладка ОС. В английской ОС буквенная база остаётся QWERTY, но RU-пунктуационный слой даст другие символы. Кандидат не пытается молча переключать язык ОС. Полноценный отдельный английский символьный слой — следующий вариант, если нужен в работе.

Убраны восемь комбинаций обычных букв для пар символов и макросы на пробеле. В исходнике DOT внутри sentence-макроса при русской раскладке ОС соответствует «ю», а не точке. Текстовые макросы можно вернуть позднее на явные кнопки после выбора языка; они не должны перехватывать обычные пары букв.

## Проверка после отдыха

1. Сравнить схему без прошивки: удобен ли пробел на левом внутреннем большом пальце. Dominant hand сама по себе не определяет удобство конкретного thumb key.
2. После успешной сборки и осознанной прошивки обеих половин набрать короткий обычный текст, отдельно «ё ж э х ъ», точку/запятую и повторные пробелы.
3. Проверить Num, 0, арифметику, десятичный разделитель в рабочем Excel, Tab/Enter и повтор Backspace.
4. Проверить Ctrl+C/V/Z, Alt+Tab, Ctrl+Shift+стрелки, Win+Space. Home-row модификаторы на A/S/D/F сохранены: их ложные срабатывания ещё нужно оценить на привычной скорости.
5. Проверить выход из каждого слоя при отпускании thumb. Сочетание одновременно NUM/NAV/FN подчиняется обычному приоритету верхнего слоя.

Основной риск кандидата — переучивание больших пальцев и языка пунктуации. До личной проверки не объединять его со стабильной веткой и не считать более удобным по одному успешному build. Для отката использовать firmware от исходного master bcaabca, предварительно сохранив артефакты; сброс настроек Bluetooth не нужен только из-за изменения keymap.

## Источники поведения

- [ZMK: слои](https://zmk.dev/docs/keymaps/behaviors/layers) — momentary включается при нажатии и выключается при отпускании.
- [ZMK: hold-tap](https://zmk.dev/docs/keymaps/behaviors/hold-tap) — tap/hold и quick-tap.
- [Схема hold-tap именно v0.2](https://github.com/zmkfirmware/zmk/blob/v0.2/app/dts/bindings/behaviors/zmk%2Cbehavior-hold-tap.yaml) — наличие использованных свойств в закреплённой версии.
- [ZMK: tap-dance](https://zmk.dev/docs/keymaps/behaviors/tap-dance) — выбор действия по числу нажатий; ожидание завершается и при другой клавише. Поэтому прежний tap-dance не означает обязательную задержку каждого пробела на весь таймер.
