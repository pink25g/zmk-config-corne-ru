# Полный сброс, прошивка и подключение к Windows

Используйте эту процедуру после изменения BLE-конфигурации или при состоянии «подключено, но не печатает».

## Подготовка

Скачайте из успешной сборки GitHub Actions три файла:

- прошивку `settings_reset`;
- прошивку `corne_left`;
- прошивку `corne_right`.

## Порядок действий

1. В Windows удалите Bluetooth-устройство `Corne`.
2. Выключите обе половины.
3. Переведите левую половину в загрузчик и скопируйте на неё `settings_reset`.
4. После перезапуска снова войдите в загрузчик левой половины и прошейте `corne_left`.
5. Переведите правую половину в загрузчик и скопируйте на неё `settings_reset`.
6. После перезапуска снова войдите в загрузчик правой половины и прошейте `corne_right`.
7. Включите обе половины.
8. На клавиатуре выберите нужный Bluetooth-профиль и выполните его очистку (`BT CLR`).
9. Снова выберите этот профиль, например `BT0`.
10. В Windows откройте добавление Bluetooth-устройства и подключите `Corne` заново.

## Проверка

Проверьте последовательно:

- печать сразу после подключения;
- работу обеих половин;
- пробуждение после 2–3 минут бездействия;
- пробуждение после 16–20 минут;
- выключение и повторное включение;
- повторное подключение Windows без удаления устройства.

Запишите, на каком именно пункте возникает сбой.
